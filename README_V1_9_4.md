# Suivi horaires — V1.9.4

## Changements
- Interface employé simplifiée avec gros boutons arrivée / départ.
- Pause chronométrée par bouton toggle.
- Arrivée et départ modifiables directement dans leurs cartes.
- File d’attente locale : une modification faite hors ligne reste sur le téléphone et est resynchronisée automatiquement à la reconnexion.
- Cache local des données employé pour permettre la réouverture hors ligne après une première connexion réussie.
- Indicateur En ligne / Hors ligne.
- Double-tap zoom neutralisé via `touch-action: manipulation` tout en conservant le pinch-to-zoom.
- Service worker V1.9.4 avec fallback de navigation hors ligne.

Aucun nouveau SQL n’est requis pour cette version.
