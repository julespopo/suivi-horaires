SUIVI DES HORAIRES — V1.1

Ouvrir index.html pour lancer la démonstration.

Nouveautés V1.1 :
- Une journée passée se complète désormais dans une seule fenêtre : arrivée + départ + pause + commentaire.
- Chaque ligne de l'historique possède un bouton « Modifier » pour corriger une journée déjà remplie.
- Les corrections sont enregistrées comme modifications manuelles dans la structure de données.

Cette version est une démonstration locale : les données sont stockées dans le navigateur (localStorage).
La future version en ligne utilisera une base de données commune, des liens personnels, un PIN et des rappels automatiques.
