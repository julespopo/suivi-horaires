# V1.9.3 — menu flottant

Le bouton engrenage n’ouvre plus une fenêtre générale. Il déploie trois actions flottantes :
- soleil/lune : bascule immédiatement le thème ;
- clé : ouvre uniquement la fenêtre de changement de PIN ;
- sortie : déconnexion directe.

Le même comportement est appliqué aux espaces employé et pilotage. Aucun changement SQL supplémentaire n’est nécessaire par rapport à la V1.9.2.
