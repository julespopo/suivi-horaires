# Suivi horaires V1.9.6

## Changements
- Fenêtre « Compléter la journée » recentrée et stabilisée sur mobile.
- Suppression du défilement horizontal accidentel dans les modales et formulaires.
- Les champs éditables restent à 16 px minimum sur mobile pour éviter le zoom automatique iOS au focus.
- L'ouverture d'une journée passée ne force plus automatiquement le focus sur l'heure d'arrivée.
- Les grilles de saisie passent proprement sur une colonne sur petit écran.
- Ajout de boutons rapides de pause : +5, +15, +30, +60 minutes.
- Ces boutons existent pour la journée du jour et dans la fenêtre de modification d'une journée passée.
- Le pinch-to-zoom à deux doigts reste disponible ; le double-tap ne provoque pas de zoom d'interface.
- Aucun changement Supabase requis.
